# 📰 Week 3 Code Challenge – Magazine Content Platform

Welcome to the **Magazine Content Platform**, a Python-based command-line application built to manage relationships between **Authors**, **Articles**, and **Magazines** using object-oriented programming (OOP) principles and direct SQL interaction with an SQLite3 database.

This project demonstrates strong model design, data relationships, and hands-on SQL querying without an ORM.

## ✨ Features

- 🧑 Create and manage **Authors**
- 🗞️ Create and manage **Magazines**
- 📝 Publish **Articles** that belong to Authors and Magazines
- 🔁 Define and traverse relationships (e.g., author → articles → magazine)
- 💾 Lightweight SQLite3 database for easy setup
- 🧪 Unit tests for all model functionality
- 🛠️ Interactive debugging shell (`lib/debug.py`)

---

## 🧰 Tech Stack

- **Python 3.8+**
- **SQLite3** – lightweight file-based relational database
- **Unittest** – built-in Python testing framework
